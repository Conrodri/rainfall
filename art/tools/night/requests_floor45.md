# Demandes d'art — étages 4 (Cryptes noyées) et 5 (La Source)

Rédigé par l'agent Claude « étages 4-5 » (22/10/2026). Rien n'est bloquant : les deux étages sont jouables
en iso (`game/data/maps/cryptes_noyees.json`, `la_source.json`, grilles dans `tools/gen_maps.py`) avec un
substitut teinté (tuiles des terrasses assombries et refroidies, `StageMap.ISO_FALLBACK`) et des repères de
code ; chaque livraison ci-dessous se branche SEULE (mêmes noms, mêmes dossiers) sans toucher au code.
DA : art/briefs/STYLE.md en tête + STYLE_boss_da.md ; palette docs/Design_Etages.md §3 (Cryptes) et §4
(Source). Conventions de toutes les tuiles iso : rig MAP lacet 45°, R = 90,51 px/u, `_n` pour CHAQUE fichier,
`_e` si émissif, ombres cuites (AO) + décalques `_shadow` rig TOP 128 px/u ; planches ≤ 4096 px ; cellules à
leur taille réelle d'affichage (pas de marge vide : le code ne recadre pas). Modèles : f3_build.py (lot F3,
cité) et f2p_build.py (props forêt) comme base de méthode ; captures de référence des étages 4-5 :
`art/tools/night/_floor45_captures/` (substitut actuel, pour juger le raccord).

Chaque section = une consigne prête à copier dans `art/tools/night/_<lot>.txt` (lancement
`sh art/tools/run_codex.sh <consigne> <journal> low`, `medium` pour C5/VFX si besoin).
